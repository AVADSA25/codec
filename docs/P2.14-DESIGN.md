# P2.14 — Installable PWA with an offline shell

Item 4 of docs/UI-PHASE2-3-PLAN.md. Web Push is P3.13 and builds on this service worker.

## Why

CODEC's PWA has a manifest but no service worker, one 2048px icon declared for every size and purpose, an
old theme colour, and no shortcuts. Chrome captures `beforeinstallprompt` on Home and nothing uses it. When
the Mac is off, the phone shows the browser's own error page, or Cloudflare's 5xx page through the tunnel.

## What

- **Service worker** `static/sw.js`, served at `/sw.js` (scope `/`, public like `/manifest.json`; it holds
  no secrets). It precaches only the shell assets: `codec.css`, `codec-shell.js`, `codec-md.js`, the vendor
  scripts, the six Plex fonts, the logo, the icons and `static/offline.html`.
  - `/static/*` GETs: cache first, refreshed in the background (stale-while-revalidate); the `?v=` stamps
    already make changed files new URLs.
  - Page navigations: always the network. If the network fails, or the tunnel answers with a gateway error
    (502, 503, 504 or 520-530) because the Mac is off, it serves `offline.html`.
  - Everything else, `/api/*` included, is never touched: the worker does not call `respondWith`, so those
    requests go to the network exactly as before and nothing tied to the session is stored.
  - A version constant names the cache; `activate` deletes older CODEC caches.
- **Offline page** `static/offline.html`: a calm "Your Mac is not reachable" screen (CODEC runs on your
  Mac; it may be asleep, off, or offline), a Try again button, and an automatic retry when the phone comes
  back online. Theme follows the saved preference; no emoji.
- **Registration** in `static/codec-shell.js`, after load, on every app page: `navigator.serviceWorker
  .register('/sw.js')`. Auth (`/auth`) does not register but is covered once a worker exists.
- **Manifest** (`routes/health.py`): icons `static/icons/icon-192.png`, `icon-512.png` (purpose any) and
  `maskable-512.png` (purpose maskable, on the dark background with the safe zone), made from the existing
  logo; `theme_color` and `background_color` `#121215`; `id` `/`; shortcuts New chat (`/chat#new`), Voice
  (`/voice`) and Start my day (`/chat#starter=day`). The apple-touch-icon links point at the 192 icon.
- **Start my day shortcut**: Chat reads `#starter=day` like `#new` and sends the existing "start my day"
  starter in a new chat. Only this fixed starter is accepted; a link cannot make CODEC send arbitrary text.
- **Install button**: the shell captures `beforeinstallprompt` on every page (Home's existing capture stays
  compatible through `window.deferredPrompt`) and shows "Install CODEC" in quick settings while an install is
  possible; on iPhone and iPad Safari, where there is no prompt, the same row explains Share, then Add to
  Home Screen. Hidden when CODEC already runs installed (display-mode standalone).

## Not in this item

Push notifications (P3.13). Caching pages or API data for offline use: not planned (the shell never stores
anything tied to the session).

## API or schema change

New public route `/sw.js` (the file from `static/`, `Service-Worker-Allowed: /`, `Cache-Control: no-cache`).
Manifest fields change. No data changes.

## Test plan

tests/test_pwa.py: `/sw.js` is public and served as JavaScript with no-cache; the worker's precache list
names only `/static/` URLs that exist and includes the offline page and fonts; the fetch handler ignores
`/api/` and non-GET requests and treats gateway errors on navigations as offline; the manifest lists the three
icons with the right sizes and purposes (files exist, sizes checked with PIL) and the three shortcuts; the shell
registers the worker and has the install row; Chat accepts only `#starter=day`. A jsdom check of the offline
page. Browser: the worker installs and controls the page (throwaway dashboard); with the dashboard stopped, a
reload shows the offline page; the Try again button reloads when the server is back. Live: `/sw.js` and the
new manifest served; icons load.

## Rollback

Revert the PR. A worker already installed on a phone keeps running until it updates; `static/sw.js` is
replaced by a tiny unregistering worker if a full rollback is needed (documented here, not shipped).
